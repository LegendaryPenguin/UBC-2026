# Interaction control-to-handler checklist

This checklist covers the implemented Gemini, Arc, and ElevenLabs paths and records how a user reaches each outcome. It is a release checklist, not a claim that external services or real-fund operations have been qualified. A browser walkthrough is still required where the verification column says code review only.

The current acceptance path follows the [corrected hackathon storyboard](hackathon-scope.md). For each sequence below, check the user's start and goal, control enablement, handler/data/authorization, immediate and completed result, cancellation/back/refresh, failure/retry, and next action. The older VFINAL coverage below remains a broader release checklist.
