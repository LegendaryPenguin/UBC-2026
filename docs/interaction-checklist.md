# Interaction control-to-handler checklist

The corrected four boards and the narrated optional follow-through below are the active acceptance checklist. Later tables retain additional control details; they are reference material unless used by those flows. This checklist does not claim external services or real-fund operations have been qualified. Verify the application paths through backend/integration tests and trace the UI handlers in code; do not rely on repeated screen checks.

The current acceptance path follows the [corrected storyboard and narrated flow](hackathon-scope.md). For each sequence below, check the user's start and goal, control enablement, handler/data/authorization, immediate and completed result, cancellation/back/refresh, failure/retry, and next action. Later sections are implementation references when those supporting controls appear in the active flow.
