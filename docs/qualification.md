# Integration qualification

This is a factual capability/evidence log, not a scope or task list. The active scope is the [corrected four-board storyboard](hackathon-scope.md): Gemini market data is the priority; ElevenLabs supports its research flow; Arc is a conditional construction/review path. Trade execution and the broader onchain position lifecycle below are not required for storyboard completion.

| Capability | Environment | Evidence | Status |
| --- | --- | --- | --- |
| Arc network | Public testnet RPC | `eth_chainId` returned `0x4cef52` (5042002). [Arc network details](https://docs.arc.io/arc/references/connect-to-arc) | Verified November 14, 2026 |
| USDC ERC-20 units | Arc testnet | `decimals()` returned 6 at `0x3600000000000000000000000000000000000000`. Arc documents 18 decimals for native gas. [Arc network details](https://docs.arc.io/arc/references/connect-to-arc) | Verified November 14, 2026 |
| Gemini discovery | Public API | The market browser now supports the documented events, upcoming, recently-settled, and event-detail endpoints. A direct public API request failed because `api.gemini.com` did not resolve from the development environment on November 14, 2026. [Gemini Markets API](https://developer.gemini.com/prediction-markets-spec/markets) | Live inventory, current schema, and settlement compatibility remain unverified |
| Gemini account access | OAuth 2.0 public client | PKCE authorization, state validation, encrypted token storage, refresh, and token revocation are implemented against the documented flow. [Gemini OAuth](https://developer.gemini.com/authentication/oauth) | Gemini OAuth app registration, user consent, private API responses, and production-grade token storage are unverified |
| Gemini order reads/cancel | Authenticated REST | Account-scoped endpoints for active, filled, and canceled orders plus explicit cancellation are implemented. Gemini recommends WebSocket for active execution and streams. [Order management](https://developer.gemini.com/rest-api/prediction-markets/order-management) | Requires an OAuth app and a linked account with the corresponding scopes. No real account request has been made |
| Gemini terms and order placement | Authenticated OAuth REST | The app fetches the latest terms and status, requires a separate user action to accept the reviewed terms version, and submits one validated limit order intent without automatic retries. [Terms](https://developer.gemini.com/rest-api/prediction-markets/terms), [Place Order](https://developer.gemini.com/rest-api/prediction-markets/order-management/place-order) | Code follows the documented one-off REST workflow. No registered OAuth client or connected trading account is available here, and Gemini API DNS is unavailable from this environment; no live terms acceptance or order response has been observed |
| Arc escrow execution | Arc testnet | Contract receipt reconciliation verifies acceptance, quote terms, payout schedule, live status, and holder claims. Outcome proposals commit Gemini evidence hashes; the contract enforces a fixed one-hour correction window and the quote-bound longstop, with public finalization and longstop refunds. [Arc network details](https://docs.arc.io/arc/references/connect-to-arc) | Contract and resolver code are implemented, but the local environment has no configured escrow address, resolver key, operator secret, or funded maker. No deployment, acceptance, proposal, resolution, or claim has been observed onchain; the new contract must be deployed before this flow can run |
| Paper research | Local app | Recorded walkthrough fixtures are in `fixtures/`. Paper quotes have no maker signature or chain receipt. | Local only |
| ElevenLabs voice | Local development | Server-side Scribe v2 transcription and text-to-speech. Microphone capture is user initiated and the app does not persist recordings. [Speech-to-text API](https://elevenlabs.io/docs/api-reference/speech-to-text/convert), [text-to-speech API](https://elevenlabs.io/docs/api-reference/text-to-speech/convert) | Key configured locally. A one-word text-to-speech request returned audio. Transcription and account retention settings unverified |
| QuickNode Streams | Provider webhook | The handler verifies QuickNode HMAC signatures and timestamp/replay limits, matches signed log pointers to independent Arc receipts, and refreshes status from escrow state. [QuickNode webhook verification](https://www.quicknode.com/guides/quicknode-products/streams/validating-incoming-streams-webhook-messages), [Webhook destination](https://www.quicknode.com/docs/streams/destinations/webhooks) | Secret, deployed public endpoint, Stream filter, and a real signed delivery are not configured or verified |

Before opening a family for live quotes, record the exact Gemini event and contract terms, the observation rule, consistent threshold semantics, the trade cutoff, and how cancellation and correction affect settlement. Confirm that the deployed escrow has the approved family and enough maker collateral, then verify that position recording reconciles the actual Arc acceptance receipt.
